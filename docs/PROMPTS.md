# Prompts

## Context Block

I am building a reusable vanilla JavaScript Canvas starter engine.

The project uses:

- index.html for the page structure
- style.css for basic styling
- main.js as the entry point
- src/canvas/setupCanvas.js for Canvas and HiDPI setup
- src/canvas/loop.js for animation
- src/input/input.js for input
- src/utils/math.js for reusable math
- docs/ for planning and AI instructions
- process/ for screenshots and iteration notes

The project uses pure Canvas with no external libraries.

My current design rule is one signal, one dominant behavior, and one visual form.

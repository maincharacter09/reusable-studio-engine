# System Charter
To make motion 
## Intent

I want this system to turn simple input into a clear visual signal keeping the relationship between human action and digital behavior easy to understand.

## Constraints

1. I will keep each template sketch focused on one main input and one dominant behavior.
2. I will use simple visual forms before adding effects or decoration.
3. I will keep planning, code, and process documentation separated into clear files.

## Tensions

- Signal vs. noise
- Control vs. variation

## Taste Vow
super simple

## Template Sketch

- Signal: mouse X position
- Parameter: circle radius and pulse speed
- Behavior: the circle changes size and pulse speed as the mouse moves
- Readability test: moving the mouse from left to right should make the change obvious within five seconds
